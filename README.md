# たたいて かぶって ジャンケンポン!

じゃんけんに **かったら たたく!** **まけたら かぶる!**
リングの上の アームレスリング台で、10人の わるものと「叩いてかぶってジャンケンポン」で しょうぶする ブラウザゲームです。

インストールは不要です。`index.html` は1ファイルで完結しているので、ブラウザで開くだけで遊べます(スマホ・タブレット・PC 対応)。

## 公開アドレスと、ホーム画面に入れる(アプリのように使う)

- 公開アドレス: **https://roguepink.github.io/janken/** (GitHub Pages。`main` に上げたものがそのまま公開される)
- LINE などに、このアドレスを貼れば送れる。貼ると、タイトルと絵(`ogp.jpg`)つきの紹介が出る
- **LINE の中で開いたときは、ホーム画面に入れられない。** 右下(または右上)のメニューから「**Safari で開く**」(iPhone)/「**他のアプリで開く**」→ Chrome(Android)を選んでから入れる
  - iPhone(Safari): 共有ボタン →「**ホーム画面に追加**」
  - Android(Chrome): メニュー(︙)→「**アプリをインストール**」または「ホーム画面に追加」
- 入れたあとは、アイコンから全画面で起動する。一度開けば、電波がなくても遊べる(`sw.js` が覚えておく)
- ゲームを直して公開すれば、**電波のある人は次に開いたときに新しい版**になる(`sw.js` はまずネットで最新を取りにいき、取れないときだけ覚えた版を出す)。
  遊んでいる最中は変わらず、開き直したときに変わる。公開から最大10分ほどは、GitHub の決まりで古いまま のことがある
- `sw.js` の `VERSION` を上げるのは、覚えるファイルの組み合わせ(`FILES`)を変えたとき。古い覚えを一斉に捨てるための番号で、ゲームを直しただけなら要らない
- `index.html` は `node scripts/build.js` で `src/` から作り直す(直したら、作り直したものも一緒に上げる)

## あそびかた

1. **タップ**で じゃんけんが はじまります。「じゃん・けん・**ぽん!**」の ぽんに あわせて、まんなかの **グー・チョキ・パー** を タップ。
   - 出せなかったら **あいこ**(「あいこで しょ!」で やりなおし)。
   - ボタンのまわりの輪が 一周したときが「ぽん」。ぴったりだと **ジャスト!**(そのターン ぶき・ぼうぐが はやくなる)。
2. **かったら** 右の **たたく**! ぶきで あいての あたまを たたく。
3. **まけたら** 左の **かぶる**! ぼうぐで あたまを まもる。
   - あいてが たたく前に かぶり終われば **ガード**(ダメージが へる)。ぎりぎりなら **ギリギリ ガード!!**
4. まちがえて 反対を おすと **おてつき**(そのターンは もう うごけない)。
5. HP が 0 に なった ほうの まけ。じゃんけんに 続けて かつと **れんしょう** で ダメージが ふえる。

画面の 上が あいて(奥)、下が あなた(手前)。左 = かぶる、まんなか = じゃんけん、右 = たたく です。

### ぶき(5種類)

おもいほど つよいけど、ふりおろすのが おそい。おもい ぶきは **ガードの上からも ダメージが とおる** ので、じゃんけんに 勝ち続ければ 相手が ガードしても 必ず たおせます。

| ぶき | はやさ | つよさ | とくちょう |
| --- | --- | --- | --- |
| ピコピコハンマー | ★★★★★ | ★ | いちばん はやい。ガードされると ほとんど きかない |
| ハリセン | ★★★★ | ★★ | はやくて いい音 |
| フライパン | ★★★ | ★★★ | バランス型 |
| 木づち | ★★ | ★★★★ | ガードの上からも ひびく |
| 100tハンマー | ★ | ★★★★★ | さいきょう。騎士のかぶとの上からでも 大ダメージ |

### ぼうぐ(5種類)

かたいほど ダメージを へらせるけど、かぶるのが おそい。かるい ぼうぐは すぐ かぶれるけど 少し いたい。

| ぼうぐ | はやさ | かたさ |
| --- | --- | --- |
| ざる | ★★★★★ | ★ |
| おなべ | ★★★★ | ★★ |
| 工事ヘルメット | ★★★ | ★★★ |
| バイクヘルメット | ★★ | ★★★★ |
| 騎士のかぶと | ★ | ★★★★★ |

### むずかしさ(3段階)

| | あいての はやさ | 受けるダメージ | 押すボタンが 光る |
| --- | --- | --- | --- |
| やさしい | ゆっくり | 少なめ | ○ |
| ふつう | ふつう | ふつう | ○ |
| むずかしい | すばやい | 多め | × |

クリアした ステージは むずかしさごとに 保存され、次のステージを えらべるように なります。

## そうさ

| | スマホ・タブレット | PC |
| --- | --- | --- |
| じゃんけん スタート | 画面を タップ | スペース / Enter |
| グー・チョキ・パー | まんなかの ボタン | 1 2 3(または Z X C) |
| かぶる | 左の 青いボタン(画面の 左下半分 どこでも) | ← / A |
| たたく | 右の 赤いボタン(画面の 右下半分 どこでも) | → / D |
| ポーズ / おと | 右上の ボタン | P・Esc / M |

タブレットや PC の 横長の画面では、かぶる・たたくボタンが 画面の 左右はしに 大きく 出ます(両手の 親指で 押しやすい)。

## 遊ぶには

そのまま `index.html` を ダブルクリック。うまく動かない ブラウザでは、このフォルダで ローカルサーバーを 立てます。

```sh
python3 -m http.server 8000
# → http://localhost:8000/ を開く
```

## つくり

画像・音声ファイルや 外部ライブラリは 使っていません。絵は すべて Canvas のパスで描き、効果音と BGM は WebAudio で 合成しています。

```
index.html          遊ぶための ファイル(src/ から 自動生成した 1ファイル版。直接は 編集しない)
src/index.html      画面(タイトル・じゅんび・けっか・ポーズ・あそびかた)
src/style.css       メニューの デザイン
src/js/util.js      共通の計算(乱数・イージング・色)
src/js/config.js    ゲームバランスの数値(ぶき・ぼうぐ・むずかしさ・CPU の強さ・10ステージ・セリフ)
src/js/rules.js     じゃんけんの勝ち負け・ダメージ・ガード判定・CPU の考え方・試合の シミュレーション(DOM なし)
src/js/art.js       じゃんけんの手・ぶき・ぼうぐ・書き文字の 絵
src/js/characters.js 相手 20人(10ステージ × 男女)と 自分(うしろ姿)の 絵
src/js/arena.js     リング・アームレスリング台・試合前の 会場(観客)
src/js/fx.js        星・火花・紙ふぶき・たて・集中線・画面ゆれ・フラッシュ・書き文字
src/js/audio.js     効果音(ぶき・ぼうぐごとの音、たいこ、ゴング、観客)と BGM
src/js/game.js      試合の進み方(じゃんけん → たたく/かぶる → けっか → KO)
src/js/render.js    画面の配置と 描画、タップ位置の 判定
src/js/input.js     タップ・キーボード
src/js/ui.js        メニュー・保存(localStorage)
src/js/main.js      起動・メインループ
scripts/build.js    src/ を index.html に まとめる
tests/              ルール・バランス・ビルド・ブラウザでの 通しプレイの テスト
```

### 変更したら

`src/` を直したら `node scripts/build.js` で `index.html` を 作り直します(古いままだと テストが 失敗します)。

### 調整する

遊びごこちは `src/js/config.js` の 数字で 変えられます(ぶきの `swing`・`power`・`pierce`、ぼうぐの `don`・`block`、
むずかしさの `cpuReact`・`window`・`grace`、CPU の強さ `cpuLevels`、ステージごとの `hp`・そうび・`crowd` など)。

### テスト

```sh
node tests/logic.test.js
node tests/build.test.js
NODE_PATH=$(npm root -g) node tests/browser.test.js   # Playwright + Chromium
```

ロジックの テストでは、じゃんけん・ダメージ・ガード判定に 加えて、ボットで 何千試合も シミュレーションして
「ステージが進むほど むずかしい」「むずかしさで 差が出る」「すばやく押せる人ほど 勝てる」ことを 確かめます。
ブラウザの テストでは、スマホ画面で 本物のタップを使って メニュー → じゃんけん → たたく / かぶる / おてつき → KO → けっか → 次のステージ まで進み、こわれた保存データや ボタンのはしのタップも 確かめ、
全10ステージ × 男女を ボットで 通しプレイして エラーが出ないことを 確かめます。

URL の おわりに `?debug` を つけると、ブラウザの コンソールから `__janken` で ゲームの状態を のぞけます(動作確認用)。
